ATIVIDADE DE RECUPERAÇÃO – FRONT-END

Projeto: StudyFlow – Aplicativo de Organização de Estudos

PARTE 1 – PESQUISA DE INTERFACE

1. O que é “Mobile First” e por que essa abordagem é importante no desenvolvimento web atual?

Mobile First é uma abordagem em que o site é planejado primeiro para telas pequenas, como celulares, e depois adaptado para telas maiores. Ela é importante porque muitas pessoas acessam sites pelo celular e porque ajuda a criar interfaces simples, rápidas e responsivas.

2. Quais são as melhores práticas para a criação de formulários web acessíveis e amigáveis para o usuário?

É importante usar rótulos claros nos campos, indicar o que deve ser preenchido, manter um layout simples, facilitar a navegação pelo teclado, mostrar mensagens de erro claras e informar ao usuário quando o preenchimento foi realizado com sucesso.

ARQUIVOS DO PROJETO

- index.html: estrutura da Landing Page.
- style.css: estilos e responsividade.
- script.js: validação do formulário.
- studyflow.svg: imagem usada na página.

COMO TESTAR

Abra o arquivo index.html em um navegador. Teste o formulário deixando os campos vazios e também digitando um e-mail inválido. A mensagem de erro aparece na própria página, sem usar alert().
